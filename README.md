# Sustainable Urban Logistics Network Optimization

Academic case study of a last-mile facility and vehicle network under cost, service, and emissions constraints.

## Included artifacts

- Final technical report and presentation in `reports/`.
- Provided case inputs, observed model tables, and saved LP/network-flow solutions in `data/`.
- Discussion of mixed-integer optimization, epsilon-constraint analysis, and goal programming in the report.

## Reproducibility status

The original capstone solver source code was not found in the supplied folders. This repository documents the completed study and preserves the available data and results; it does not claim to offer a runnable optimization implementation. The distance input is explicitly a 50-route sample, which may be insufficient to recreate the full network.

The reported three-site electric-network recommendation and cost/service targets are historical project findings, not independently reproduced results. Refer to the technical report for assumptions, units, model definitions, and authorship. This is a group academic project presented in Xinru Tang's portfolio; attribution is retained in the source documents.
